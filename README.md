# Portfolio — Moula Raoul

Site personnel de **Moula Raoul**, orienté vers la programmation scientifique, la modélisation mathématique, les simulations 3D et les technologies éducatives.

- **Page d'accueil** : `index.html` (HTML/CSS autonomes, sans dépendance externe).
- **Projets publics** : [Atelier de simulations pédagogiques](https://github.com/MoulaRaoul/atelier-simulations-minesec) et [Simulation and Modeling of Natural Processes](https://github.com/MoulaRaoul/simulation-modeling-natural-processes).
- **Profil GitHub** : [github.com/MoulaRaoul](https://github.com/MoulaRaoul).
- **Présentation de profil prête à réutiliser** : [PROFILE_README.md](PROFILE_README.md).

## Publier avec GitHub Pages

Dans **Settings → Pages**, sélectionner **Deploy from a branch**, la branche `main` et le dossier `/ (root)`. Le site pourra alors être accessible à `https://moularaoul.github.io/`.

## Notes

Ce site est un portfolio **personnel** : il ne doit pas être interprété comme une publication officielle du MINESEC ni d'une autre institution.

Les réalisations sont décrites sans prétendre que les essais scientifiques, pédagogiques ou de compatibilité sont achevés lorsque ce n'est pas le cas.
